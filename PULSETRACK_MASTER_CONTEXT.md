PulseTrack — Master Engineering Context, Codebase Audit & Split-Phase Rebuild Specification
1. Project Identity, Mission & Constraints
Product: PulseTrack — ultra-resilient disaster management and personal emergency response ecosystem.

Team: Code Tracers (Shameem Muhammad, Mujeeb Ur Rahiman, Mohammad Ifaaz Beig B.).

Budget Doctrine: Strictly $0 / Free Tier (Supabase Free Tier: 500MB DB / 1GB Storage / 200 concurrent Realtime connections; Expo EAS Free Tier for Android .apk builds; Vercel Hobby Tier for web dashboard; Google Gemini Free Tier API for triage, transcription, and RAG).

Geography & Emergency Context: Initially grounded for India (112 unified emergency, 100 Police, 101 Fire, 108 Ambulance, 1078 Disaster, 1091 Women Helpline) while displaying global incidents on the Web Command Center map.

Tier 1 (Internet Available): Split-write to Supabase (incidents_public anonymized GPS/status + incidents_private identity/medical/media/transcripts), automatic audio & short video capture uploaded to emergency_media bucket, Gemini multimodal transcription + AI triage via optimistic-locking Postgres RPC, live push to Global Command Center & Family Live Alert Page, and live delivery receipts back on the victim's phone. Graceful REST fallback if Supabase Realtime hits Free Tier limits.

Tier 2 (Cellular Only, No Data): Triggers if Tier 1 fails/times out (~4000ms). Compiles compressed payload SOS|Lat,Lng|Battery%|Name|AlertLink targeting real user-saved Family/ICE contacts and 112. Android native EAS build uses SmsManager (SEND_SMS) for silent background dispatch; iOS opens pre-filled expo-sms native composer cleanly.

Tier 3 (Total Grid Collapse): Autonomous BLE Mesh (react-native-ble-plx, Service UUID 0xFD6F) advertising compressed hex SOS payloads for nearby Safe Mode PulseTrack devices to detect/relay, and powering off-grid Group Travel squad awareness.

7. Complete Target Functional Requirements (End-to-End)
A. First-Run Onboarding & App Intro (Persisted via AsyncStorage)
Brand Splash Fade-In: Fast (~1.2s) pure-OLED dark fade-in with restrained PulseTrack pulse mark (never delays an active emergency).

Profile & Family/ICE Contact Setup: User enters full name, blood group, medical notes, and saves real Emergency Contacts (name, relationship, phone number; editable later in Settings; persisted offline in AsyncStorage and synced to Supabase).

Unified Permissions Card: Single transparent checklist for Location (Always), Microphone, Camera, Bluetooth, and Notifications with 1-line rationale and live Granted / Allow status pills.

Interactive Feature Briefing: 3-card skippable walkthrough explaining the 3-Tier Fail-Safe, Operating Modes, and Stealth Mode.

B. Mode-First Navigation Architecture
Landing screen (post-onboarding) is the Mode Selection Hub (no immediate SOS trigger until a mode is entered):

Default Mode Page: Personal standby safety, tactile Hold-for-SOS, 1-tap Indian emergency hotlines (112, 100, 101, 108, 1091), ICE contact readiness summary, low-battery GPS standby.

Travel — Solo Mode Page: Live GPS breadcrumb tracking, shareable live trip tracking URL for family, configurable Dead-Man's Check-In Timer (auto-triggers SOS if missed), elevated fall/impact threshold.

Travel — Group Mode Page (BLE Mesh + Squad Nicknaming): Create/join squad via BLE Mesh (+ internet sync when available); assign and edit custom nicknames per group peer ID (e.g., "Mujeeb", "Ifaaz", "Mom") showing live peer proximity (RSSI), battery %, safety status, and one-tap squad-wide SOS broadcast.

Disaster Mode Page: Maximum-sensitivity structural impact (G-force) & acoustic collapse (dB) detection with locked threshold sliders, persistent BLE Mesh relay for trapped citizens, instant pure-OLED Stealth Mode killswitch, 3000Hz local-asset acoustic beacon, and pinned Hybrid RAG Survival Assistant.

C. Real Emergency Capture, Telemetry, Transcription & AI Triage
Live Telemetry: Real accelerometer G-force, ambient mic dB sampling, GPS + altitude, and expo-battery level using atomic Zustand selectors (zero UI jank).

Auto Voice + Video Capture on Emergency: Triggering SOS (manually or via sensor breach after false-alarm countdown) automatically records compressed emergency audio and/or short video clip (expo-camera + expo-audio), uploads to Supabase Storage emergency_media, and links URLs to incidents_private (with offline local queue + automatic retry when connectivity returns).

Extra Voice Notes: Victim Console allows recording and sending unlimited follow-up voice notes appended to the incident timeline.

Automatic Transcription & AI Triage: Supabase Edge Function (invoking Gemini multimodal API) transcribes every audio/voice clip into readable text for responders and family members, and executes claim_and_triage_incident to store real severity (critical/high/medium/low) and concise actionable triage summary.

Live Delivery Receipts: Victim Console displays real-time status progression (Sent to Command Center → ICE Notified → AI Triage Priority → Responder Acknowledged).

D. Working Interactive Maps
react-native-maps configured cleanly for both iOS (Expo Go Apple Maps) and Android (EAS Dev Client) with explicit dimensions, dark tactical map styling, live user pin + accuracy circle, danger/safe zone polygons, nearby BLE mesh pins, and Travel Solo route polyline.

E. True Hybrid RAG Survival Assistant
Expanded Offline Knowledge Base: Rich, medically verified disaster & trauma JSON corpus (earthquakes, structural collapse, floods, high-rise fire/smoke, arterial bleeding, CPR, fractures, gas leaks, landslides, hostile threats, heatstroke/hypothermia, off-grid water safety).

Online RAG Mode: Retrieves top matching local protocol chunks and sends them as strict grounded context to a Gemini Edge Function so users can ask natural-language crisis questions and receive calm, step-by-step grounded instructions.

Offline Mode: Fast local synonym/symptom search paired with tappable visual triage decision trees requiring zero typing under panic.

F. Companion Web Application (Next.js + Tailwind on Vercel, Same Supabase Backend)
Global Command Center (/ or /command): Live world map displaying all active incidents_public victims globally via Supabase Realtime. Selecting a victim opens a responder triage drawer showing GPS, battery, tier, AI triage priority & summary, audio/video evidence player, full readable transcripts of all voice notes, and "Acknowledge / Mark Rescued" controls that push live updates back to the victim's phone.

Saved Contact / Family Live Alert Page (/alert/[incidentId]?token=...): Direct secure link sent to saved family/ICE contacts upon emergency trigger. Displays a calm, high-clarity live status dashboard for that specific victim: live map pin, battery %, operating mode, blood group/medical notes, audio/video playback, readable voice-note transcripts, and 1-tap navigation/emergency dial actions.
